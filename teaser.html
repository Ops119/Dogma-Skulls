The lore

The Dogma

Everything fades.
What is etched remains.
I

The Void

Before the first block there was only the void: black, silent, unmarked. Then a single orange spark was struck into the dark, and the void learned what it meant to be written on.

II

The Etching

The Dogma holds that nothing true is merely spoken. It is etched. Line by line, proof by proof, each mark is carved into the chain and stacked on the last, never to be unwritten. The skulls are those marks, given a face.

III

The Skull

Bone is what remains when everything else is stripped away: no title, no mask, no promise. The order chose the skull as its sigil because it is honest. It is the one face every holder will one day share, and the one face no one can counterfeit. Cut into facets, it becomes geometry: the divine made visible as angles and orbits.

IV

The Coin

Set into the brow is the coin, the third eye of the order. It does not watch the living. It keeps the count. Two hundred and twenty-one skulls were drawn from the first light, each wearing the flame differently. One was set apart: the Prime Skull, the source from which all the others burn.

The Tenets

  3. What is etched is never erased.Permanence is the only prayer.
  4. Many faces. One Dogma.221 etchings, one faith, one Prime.
